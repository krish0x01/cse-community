The premier digital commons for Computer Science & Engineering students. Read anonymous confessions, download verified lecture notes & PYQs, discover hackathons & internships, and attend campus tech events.

---

## ⚡ Highlights & Features

- **🤐 100% Anonymous Confessions**: Zero data profiling, client headers stripped, interactive likes & nested comments.
- **📚 Academic Resource Vault**: Download handwritten notes, solved past-year questions (PYQ), lab codes, and placement roadmaps.
- **🚀 Opportunity Radar**: Curated internships, hackathons, open-source programs, and research fellowships.
- **📅 Campus Tech Events**: Live meetups, workshops, coding contests, and guest speaker sessions.
- **🛡️ Community Governance**: Transparent moderation dashboard and rule reporting.
- **💎 Dark Cyber Aesthetic**: Built with sleek glassmorphism, responsive micro-animations, and HSL neon accents.

---

## 🛠️ Tech Stack

- **Framework**: [Next.js 14](https://nextjs.org/) (App Router, Server Actions & API Route Handlers)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/) with Lucide Icons
- **Database / Backend**: [Supabase](https://supabase.com/) (PostgreSQL + Row-Level Security + Storage + Realtime)
- **Deployment**: [Vercel](https://vercel.com/)

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/krish0x01/cse-community.git
cd cse-community
```

### 2. Install dependencies
```bash
npm install
```

### 3. Setup environment variables
Create a `.env.local` file in the root directory and add:
```env
NEXT_PUBLIC_SUPABASE_URL=https://your-project-id.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-key
SUPABASE_SERVICE_ROLE_KEY=your-service-role-key
```

### 4. Run the development server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
